# FridayProject9
Instructions for testing with your own api key
First, obtain an OpenAI Api Key. If you do not have one, you can create one on the OpenAI website after creating an account
Next, generate an API Key using your OpenAI account settings
After you generate your key, create a new .env file in the same directory as the gui.py file
Open the .env file and add your API key 
Run the application and interact with the GUI
